# Кошелёк v1.10

Изменения:
- Подсказки мест теперь привязаны к категории.
- Сохранённые места одной категории не показываются в другой.
- Приложение предлагает ранее введённые места из истории даже без галочки «Запомнить».
- По мере ввода работает автодополнение: например, «ав» → «Автобус».
- Быстрые подсказки прокручиваются горизонтально и больше не ломают верстку длинными названиями.
- Старые сохранённые места автоматически распределяются по категориям на основе истории операций.
- В настройках сохранённые места сгруппированы по категориям.

## v1.11
- Экспорт резервной копии на iPhone теперь использует системное меню «Поделиться» с JSON-файлом; в iOS можно выбрать «Сохранить в Файлы».
- Добавлен запасной вариант открытия/скачивания JSON, если Web Share недоступен.
- Улучшена диагностика Face ID/WebAuthn: приложение показывает, доступна ли системная биометрия, и объясняет необходимость HTTPS/localhost.
